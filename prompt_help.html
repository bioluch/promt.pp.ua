JS PROMPT Help & Documentation

JS PROMPT is a professional Progressive Web Application that transforms ideas and task descriptions into structured, high-quality prompts for Claude AI — entirely in your browser, with no data sent to external servers.

AI Prompt Generator PDF/DOCX to Markdown Markdown Editor 9-Stage Error Checker Voice Input (Whisper) 100% Offline PWA EN / UK / ES DeepSeek API

PDF / DOCX Converter

Convert PDF and DOCX files to clean Markdown — preserving headings, lists, tables, inline formatting. Runs offline via Pyodide (PDF: pdfminer.six; DOCX: built-in OOXML converter).

First use: Phase 2 packages (pypdf, pdfminer.six, python-docx, Pillow ~12 MB) are downloaded on the first PDF conversion — DOCX needs no extra packages. Watch the spinner. After the first session, packages are cached offline.

PDF conversion pipeline

PDF files use a two-engine approach: pdf2md (primary, @opendocsg) for quality output, with pdfminer.six as automatic fallback. DOCX is parsed directly from its OOXML: headings (incl. numbering), real list numbering and nesting, bold/italic/strike, sub/superscript, hyperlinks, table of contents as links, footnotes, tables (layout tables are linearized), code blocks, quotes, equations (as LaTeX) and image placeholders (media/…).

How to use — step by step

1

Paste your text

Click the Error Checker tab. Paste your prompt or any text into the input area. There is no length limit, but optimal results are for texts of 50–2000 words.

2

3

  • Words — total word count of your text
  • Sentences — sentence count
  • Errors — number of issues found (red if >0)
  • Claude Tokens — estimated tokens when sending to Claude API
  • Quality — overall quality score (see below)
4

Examine highlighted text

Below the stats, a Highlighted text card shows your text with errors underlined. Hover over any highlight to see a tooltip with the error description. Error colours indicate type:

Spelling / Grammar Repetition / Punctuation Case Style / Clichés Passive voice Structure
5

Fix errors — three ways

Option A — Click a suggestion: in the error list, each error shows the problem word and blue clickable suggestions. Click a suggestion to apply it immediately. The stats update automatically.

Option B — Apply All Fixes: click the Apply All Fixes button to accept all suggestions at once.

Option C — Manual edit: edit the text directly in the input area, then click Check again.

6

Save or copy the corrected text

After applying fixes, two buttons appear: Save Fixed .md — opens the styled save dialog; Copy Fixed Text — copies to clipboard.

Understanding Claude Tokens

What are tokens? Claude API processes text in tokens — roughly 1 token ≈ 4 characters or ¾ of a word in English (Ukrainian text uses more tokens per word). The Claude Tokens counter shows an estimate of how many tokens your prompt will consume when sent to Claude.

4,000 – 8,000ModerateConsider condensing

How to create a Scheduled Job

1

Save a prompt first

Go to the Prompt Generator, generate a prompt, and click 💾 Save to Account. Only saved prompts appear in the Scheduler dropdown.

2

Select the prompt

Open the Scheduler tab, find the Prompt to execute dropdown, choose your prompt (listed as "Domain — Title").

3

Choose Target AI and schedule

4

Click "Schedule Job"

A confirmation toast appears. The job is listed below in the Scheduled Jobs section with status pending.

5

Wait for execution

The server-side Scheduler checks for due jobs periodically. When the run time arrives, it sends the prompt to the AI, stores the response, and updates the status.

Click 📋 Results on any job to see all past run outputs. Each result shows: timestamp, status, token count, duration, and the full AI response. Download as .md, .txt, or .docx, or copy to clipboard.

API Keys & AI Providers

JS PROMPT works without any key (the built-in local engine), but AI providers give noticeably better results. This section explains what each key is used for, where to get it and how to add it to the app.

What keys are used for

DeepSeekAI prompt generation (the DeepSeek AI engine) and translation of Ukrainian/Spanish input to English. Requests with your personal key go from your browser straight to DeepSeek.
Any providerScheduled jobs (Scheduler). The job runs on the server with the key saved in your account for that provider. For DeepSeek, Gemini and Claude the platform key is used if you have not added your own.

Opening the key manager

1

Open the dialog

Click API Keys in the main menu, or press Ctrl+Shift+K.

2

Choose the provider tab

DeepSeek, Claude and Gemini have built-in tabs. A green dot next to a tab means a key is saved; a grey dot means it is not.

3

Paste the key and press Save

The key is stored in this browser and — if you are signed in — in your account, so scheduled jobs can use it. After saving, only a masked placeholder is shown.

Adding another provider (OpenAI, Groq, Mistral, …)

Press + next to the provider tabs, enter the provider name exactly as shown in the “Name in the app” column below and, optionally, the key prefix, then press Create Provider, paste the key and press Save. The name is how the Scheduler finds your key: “GPT4” becomes gpt4, while “GPT-4” would become gpt_4 and the key would not be found.

Security and costs

  • Treat a key like a password: never paste it into prompts, chats or public files.
  • Set a monthly spending limit in the provider console where available.
  • If a key may have leaked, revoke it in the provider console, create a new one and save it again here.
  • To replace a key, save a new one on the same tab. A custom provider and its key are removed with the bin button on its tab.
  • Export / Import in the dialog moves your keys between devices as a JSON file — store that file securely.

FAQ

Why does it take long to load on first visit? ▼
Pyodide (~8 MB) downloads on first load and is cached by the Service Worker. PDF/DOCX packages (~12 MB) download only when you first use the Converter. All subsequent sessions are instant.
Do I need a DeepSeek API key? ▼
No. The local Python engine generates prompts without any key. DeepSeek is optional and provides higher quality for complex domains.
Is my text sent to any server? ▼
Local engine: no — all processing in your browser. DeepSeek engine: your text is sent to api.deepseek.com only. No data goes to our servers.
What file formats does the converter support? ▼
.pdf — pdf2md (primary) and pdfminer.six (fallback).
.docx — built-in OOXML converter (no extra packages).
Output is always clean Markdown (.md).
How does the Probability Yardstick work? ▼
For analytical domains (intelligence, risk, financial, medical, legal), generated prompts include a standardised Probability Yardstick — a scale from "Almost certainly (>95%)" to "Almost certainly not (<5%)". Every probability claim must reference this scale and cite its source.
How do I reset the app? ▼
DevTools → Application → Storage → Clear site data. This removes localStorage (saved files, API key, language) and Service Worker cache.

JS PROMPT працює і без ключа (вбудований локальний рушій), але з AI-провайдерами результати помітно кращі. У цьому розділі пояснено, для чого потрібен кожен ключ, де його отримати і як додати в застосунок.

Для чого використовуються ключі

DeepSeekAI-генерація промтів (рушій DeepSeek AI) і переклад українського/іспанського тексту англійською. Запити з вашим особистим ключем ідуть із браузера напряму до DeepSeek.
Будь-який провайдерЗаплановані завдання (планувальник). Завдання виконується на сервері з ключем, збереженим у вашому акаунті для цього провайдера. Для DeepSeek, Gemini і Claude, якщо власного ключа немає, використовується ключ платформи.

Як відкрити менеджер ключів

1

Відкрийте вікно

Натисніть API-ключі в головному меню або Ctrl+Shift+K.

2

Оберіть вкладку провайдера

DeepSeek, Claude і Gemini мають вбудовані вкладки. Зелена крапка біля вкладки — ключ збережено, сіра — ні.

3

Вставте ключ і натисніть «Зберегти»

Ключ зберігається в цьому браузері, а якщо ви увійшли — і в акаунті, щоб ним могли користуватися заплановані завдання. Після збереження показується лише замаскований заповнювач.

Додавання іншого провайдера (OpenAI, Groq, Mistral, …)

Натисніть + поруч із вкладками, введіть назву провайдера точно як у колонці «Назва в застосунку» нижче й, за бажанням, префікс ключа, натисніть Create Provider, вставте ключ і натисніть Зберегти. За назвою планувальник знаходить ваш ключ: «GPT4» стає gpt4, а «GPT-4» стало б gpt_4 — і ключ не знайшовся б.

Безпека та витрати

  • Ставтеся до ключа як до пароля: не вставляйте його в промти, чати чи публічні файли.
  • Де можливо, встановіть місячний ліміт витрат у консолі провайдера.
  • Якщо ключ міг потрапити до сторонніх, відкличте його в консолі провайдера, створіть новий і збережіть тут знову.
  • Щоб замінити ключ, збережіть новий на тій самій вкладці. Користувацького провайдера разом із ключем видаляє кнопка-кошик на його вкладці.
  • Експорт / Імпорт у вікні переносить ключі між пристроями у файлі JSON — зберігайте цей файл у надійному місці.

FAQ

Чому перше завантаження таке тривале? ▼
Pyodide (~8 МБ) завантажується при першому відвідуванні і кешується Service Worker. Пакети PDF/DOCX (~12 МБ) завантажуються лише при першому використанні Конвертера. Всі наступні сесії — миттєві.
Чи потрібен API-ключ DeepSeek? ▼
Ні. Локальний Python-рушій генерує промти без ключа. DeepSeek — опціональний і забезпечує вищу якість для складних доменів.
Чи передається мій текст на сервер? ▼
При використанні локального рушія — ні, весь розрахунок у браузері. При використанні DeepSeek — текст надсилається лише до api.deepseek.com. На наші сервери дані не потрапляють.
Як скинути додаток? ▼
DevTools → Application → Storage → Clear site data. Це видаляє localStorage (збережені файли, API-ключ, мову) та кеш Service Worker.

Claves API y proveedores de IA

JS PROMPT funciona sin ninguna clave (el motor local integrado), pero con proveedores de IA los resultados son notablemente mejores. Esta sección explica para qué sirve cada clave, dónde obtenerla y cómo añadirla a la aplicación.

Para qué se usan las claves

DeepSeekGeneración de prompts con IA (motor DeepSeek AI) y traducción del texto ucraniano/español al inglés. Las solicitudes con su clave personal van del navegador directamente a DeepSeek.
Cualquier proveedorTareas programadas (Programador). La tarea se ejecuta en el servidor con la clave guardada en su cuenta para ese proveedor. Para DeepSeek, Gemini y Claude se usa la clave de la plataforma si no ha añadido la suya.

Cómo abrir el gestor de claves

1

Abra el diálogo

Pulse Claves API en el menú principal o Ctrl+Shift+K.

2

Elija la pestaña del proveedor

DeepSeek, Claude y Gemini tienen pestañas integradas. Un punto verde indica que hay una clave guardada; uno gris, que no.

3

Pegue la clave y pulse Guardar

La clave se guarda en este navegador y, si ha iniciado sesión, en su cuenta, para que la usen las tareas programadas. Después solo se muestra un marcador enmascarado.

Añadir otro proveedor (OpenAI, Groq, Mistral, …)

Pulse + junto a las pestañas, escriba el nombre del proveedor exactamente como en la columna «Nombre en la app» y, opcionalmente, el prefijo de la clave; pulse Create Provider, pegue la clave y pulse Guardar. El Programador encuentra su clave por ese nombre: «GPT4» se convierte en gpt4, mientras que «GPT-4» sería gpt_4 y la clave no se encontraría.

FAQ

¿Por qué tarda en cargar la primera vez? ▼
Pyodide (~8 MB) se descarga en la primera visita y el Service Worker lo almacena en caché. Los paquetes PDF/DOCX (~12 MB) solo se descargan en el primer uso del Conversor.
¿Necesito una clave API de DeepSeek? ▼
No. El motor Python local genera prompts sin ninguna clave. DeepSeek es opcional y proporciona mayor calidad para dominios complejos.
¿Se envía mi texto a algún servidor? ▼
Motor local: no — todo el procesamiento en su navegador. Motor DeepSeek: su texto se envía solo a api.deepseek.com. No llegan datos a nuestros servidores.
¿Cómo reinicio la aplicación? ▼
DevTools → Application → Storage → Clear site data. Esto elimina localStorage y el caché del Service Worker.
