JS PROMPT Help & Documentation

JS PROMPT is a professional Progressive Web Application that transforms ideas and task descriptions into structured, high-quality prompts for Claude AI — entirely in your browser, with no data sent to external servers.

PDF / DOCX Converter

Convert PDF and DOCX files to clean Markdown — preserving headings, lists, tables, inline formatting. Runs offline via Pyodide (PDF: pdfminer.six; DOCX: built-in OOXML converter).

First use: Phase 2 packages (pypdf, pdfminer.six, python-docx, Pillow ~12 MB) are downloaded on the first PDF conversion — DOCX needs no extra packages. Watch the spinner. After the first session, packages are cached offline.

PDF conversion pipeline

PDF files use a two-engine approach: pdf2md (primary, @opendocsg) for quality output, with pdfminer.six as automatic fallback. DOCX is parsed directly from its OOXML: headings (incl. numbering), real list numbering and nesting, bold/italic/strike, sub/superscript, hyperlinks, table of contents as links, footnotes, tables (layout tables are linearized), code blocks, quotes, equations (as LaTeX) and image placeholders (media/…).

How to use — step by step

1

Paste your text

Click the Error Checker tab. Paste your prompt or any text into the input area. There is no length limit, but optimal results are for texts of 50–2000 words.

2

3

  • Words — total word count of your text
  • Sentences — sentence count
  • Errors — number of issues found (red if >0)
  • Claude Tokens — estimated tokens when sending to Claude API
  • Quality — overall quality score (see below)
4

Examine highlighted text

Below the stats, a Highlighted text card shows your text with errors underlined. Hover over any highlight to see a tooltip with the error description. Error colours indicate type:

Spelling / Grammar Repetition / Punctuation Case Style / Clichés Passive voice Structure
5

Fix errors — three ways

Option A — Click a suggestion: in the error list, each error shows the problem word and blue clickable suggestions. Click a suggestion to apply it immediately. The stats update automatically.

Option B — Apply All Fixes: click the Apply All Fixes button to accept all suggestions at once.

Option C — Manual edit: edit the text directly in the input area, then click Check again.

6

Save or copy the corrected text

After applying fixes, two buttons appear: Save Fixed .md — opens the styled save dialog; Copy Fixed Text — copies to clipboard.

Understanding Claude Tokens

What are tokens? Claude API processes text in tokens — roughly 1 token ≈ 4 characters or ¾ of a word in English (Ukrainian text uses more tokens per word). The Claude Tokens counter shows an estimate of how many tokens your prompt will consume when sent to Claude.
Token rangeApproximate costRecommendation
< 1,000Very lowIdeal for simple tasks
1,000 – 4,000LowStandard prompt — good balance
4,000 – 8,000ModerateConsider condensing
> 8,000HighSplit into smaller prompts

API Keys & AI Providers

JS PROMPT supports multiple AI providers for prompt generation and Scheduled Jobs. The active provider for Prompt Generator is selected per session; providers for the Scheduler are configured platform-wide by the administrator.

Adding AI providers (Admin only)

Administrators configure providers in Admin Panel → AI Providers. Each provider needs: a unique key, display label, endpoint URL (OpenAI-compatible /v1/chat/completions), model name, and optional auth header/prefix.

Built-in providers (DeepSeek, Gemini, Claude) are pre-configured. Custom OpenAI-compatible endpoints can be added as additional providers.

Entering your DeepSeek API Key

The DeepSeek engine (for Prompt Generator) requires your personal API key from platform.deepseek.com.

1

Get your key

Visit platform.deepseek.com → API Keys → Create. The key starts with sk-.

2

Open the key dialog

Press Ctrl+Shift+K. This reveals a hidden API Key button in the header and immediately opens the key entry dialog.

3

Paste and save

Paste your key into the input field and click Save. The key is stored in your browser's localStorage; if you are signed in, it is also saved to your account so scheduled jobs can use it. Requests made with your personal key go directly from your browser to DeepSeek. The key is never shown after saving (the field shows a placeholder instead).

4

Select DeepSeek engine

In the Generation Engine selector on the main page, switch to DeepSeek. Your account balance appears in the app footer with a manual refresh button.

Server-side key: on production (promt.pp.ua), the platform key is set in a server-side .env file — the key never appears in client code. Your personal key overrides it for your session.

FAQ

Why does it take long to load on first visit? ▼
Pyodide (~8 MB) downloads on first load and is cached by the Service Worker. PDF/DOCX packages (~12 MB) download only when you first use the Converter. All subsequent sessions are instant.
Do I need a DeepSeek API key? ▼
No. The local Python engine generates prompts without any key. DeepSeek is optional and provides higher quality for complex domains.
Is my text sent to any server? ▼
Local engine: no — all processing in your browser. DeepSeek engine: your text is sent to api.deepseek.com only. No data goes to our servers.
What file formats does the converter support? ▼
.pdf — pdf2md (primary) and pdfminer.six (fallback).
.docx — built-in OOXML converter (no extra packages).
Output is always clean Markdown (.md).
How does the Probability Yardstick work? ▼
For analytical domains (intelligence, risk, financial, medical, legal), generated prompts include a standardised Probability Yardstick — a scale from "Almost certainly (>95%)" to "Almost certainly not (<5%)". Every probability claim must reference this scale and cite its source.
How do I reset the app? ▼
DevTools → Application → Storage → Clear site data. This removes localStorage (saved files, API key, language) and Service Worker cache.

Конвертер PDF / DOCX

Конвертуйте PDF і DOCX-файли у чистий Markdown — зі збереженням заголовків, списків, таблиць та форматування. Працює офлайн через Pyodide.

Перший раз: пакети Фази 2 (pypdf, pdfminer.six, python-docx, Pillow ~12 МБ) завантажуються при першій конвертації PDF. Після першої сесії кешуються офлайн. DOCX не потребує додаткових пакетів.

DOCX розбирається напряму з OOXML: заголовки (з нумерацією), справжня нумерація та вкладеність списків, жирний/курсив/закреслений, верхні/нижні індекси, гіперпосилання, зміст як посилання, виноски, таблиці (таблиці-макети розгортаються в текст), блоки коду, цитати, формули (LaTeX) та заглушки зображень (media/…).

FAQ

Чому перше завантаження таке тривале? ▼
Pyodide (~8 МБ) завантажується при першому відвідуванні і кешується Service Worker. Пакети PDF/DOCX (~12 МБ) завантажуються лише при першому використанні Конвертера. Всі наступні сесії — миттєві.
Чи потрібен API-ключ DeepSeek? ▼
Ні. Локальний Python-рушій генерує промти без ключа. DeepSeek — опціональний і забезпечує вищу якість для складних доменів.
Чи передається мій текст на сервер? ▼
При використанні локального рушія — ні, весь розрахунок у браузері. При використанні DeepSeek — текст надсилається лише до api.deepseek.com. На наші сервери дані не потрапляють.
Як скинути додаток? ▼
DevTools → Application → Storage → Clear site data. Це видаляє localStorage (збережені файли, API-ключ, мову) та кеш Service Worker.

Claves API y proveedores de IA

JS PROMPT admite múltiples proveedores de IA para la generación de prompts y el Programador. El proveedor activo para el Generador de prompts se selecciona por sesión; los proveedores para el Programador son configurados en toda la plataforma por el administrador.

Añadir proveedores de IA (solo administrador)

Los administradores configuran los proveedores en Panel de administración → Proveedores de IA. Cada proveedor necesita: una clave única, etiqueta visible, URL de endpoint (compatible con OpenAI /v1/chat/completions), nombre del modelo y encabezado/prefijo de autorización opcional.

Proveedores incorporados (DeepSeek, Gemini, Claude) están preconfigurados. Los endpoints compatibles con OpenAI personalizados se pueden agregar como proveedores adicionales.

FAQ

¿Por qué tarda en cargar la primera vez? ▼
Pyodide (~8 MB) se descarga en la primera visita y el Service Worker lo almacena en caché. Los paquetes PDF/DOCX (~12 MB) solo se descargan en el primer uso del Conversor.
¿Necesito una clave API de DeepSeek? ▼
No. El motor Python local genera prompts sin ninguna clave. DeepSeek es opcional y proporciona mayor calidad para dominios complejos.
¿Se envía mi texto a algún servidor? ▼
Motor local: no — todo el procesamiento en su navegador. Motor DeepSeek: su texto se envía solo a api.deepseek.com. No llegan datos a nuestros servidores.
¿Cómo reinicio la aplicación? ▼
DevTools → Application → Storage → Clear site data. Esto elimina localStorage y el caché del Service Worker.
